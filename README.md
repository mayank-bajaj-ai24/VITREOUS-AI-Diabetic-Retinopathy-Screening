# NETRA-National-Eye-Triage-Retinal-Assessment
NETRA is a modern Clinical Decision Support System (CDSS) for rural Diabetic Retinopathy screening. It combines dual-track AI (UNet++ lesion segmentation + EfficientNet-B4/ResNet-50 fusion), Explainable AI heatmaps, and MATLAB Simulink discrete-event modeling to optimize diagnostic precision, image quality gating, and clinic patient flow.
